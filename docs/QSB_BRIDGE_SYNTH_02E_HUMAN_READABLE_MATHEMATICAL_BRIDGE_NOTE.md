# QSB-BRIDGE-SYNTH-02E Human-Readable Mathematical Bridge Note

## 1. Purpose

QSB-BRIDGE-SYNTH-02E ist eine menschenlesbare mathematische Brueckennotiz.

Sie erklaert den Kern der QSB-Brueckenidee in einer Form, die intern gut anschlussfaehig ist: nicht als Beweis, nicht als neue Numerik, sondern als roter Faden zwischen mathematischem Anker und aktueller methodischer Brueckensynthese.

Die Notiz verbindet:

```text
K_ij = <psi_i | psi_j>
d_ij = -l0 * log(|K_ij|)
```

mit dem Stand aus 02A, 02B und 02C: Die bisherigen Artefakte stuetzen eine methodische Bridge-Synthesis-Map, keine fertige physikalische Raumzeit-These.

## 2. The core question

Die Kernfrage ist schlicht:

```text
Kann aus Beziehungen zwischen Zustaenden eine strukturierte, distanzartige Ordnung gelesen werden?
```

In QSB-Sprache heisst das nicht sofort: Raumzeit ist bewiesen. Es heisst vorsichtiger: Wir schauen, ob Korrelationen, Ueberlappungen und Relationen so organisiert werden koennen, dass daraus eine methodisch pruefbare Brueckenstruktur entsteht.

Der aktuelle Stand ist deshalb kein Endpunkt, sondern eine geordnete Zwischenstufe: vorhandene Artefakte werden in einer methodischen Karte zusammengefuehrt.

## 3. Mathematical anchor

Der mathematische Anker lautet:

```text
K_ij = <psi_i | psi_j>
```

`K_ij` wird hier als overlap/correlation object zwischen zwei Zustaenden gelesen. Die Zustaende koennen als `psi_i` und `psi_j` notiert werden. Der Ausdruck sagt, wie stark diese beiden Zustaende in der verwendeten Darstellung miteinander ueberlappen oder korrelieren.

Menschenlesbar:

```text
Wenn zwei Zustaende stark miteinander verwandt sind, ist ihr Overlap gross.
Wenn zwei Zustaende schwach miteinander verwandt sind, ist ihr Overlap klein.
```

In der Brueckenidee ist `K_ij` damit kein fertiger Raumzeitbaustein. Es ist ein relationaler Eingang: ein Mass fuer Beziehungstaerke, aus dem spaeter eine distanzartige Lesart konstruiert werden kann.

## 4. From correlation to distance

Die distanzartige Lesart wird so notiert:

```text
d_ij = -l0 * log(|K_ij|)
```

Diese Formel liest Korrelationsstaerke als Entfernungsaehnlichkeit:

```text
starke Korrelation  -> kleine distanzartige Groesse
schwache Korrelation -> groessere distanzartige Groesse
```

`l0` ist dabei ein Skalenfaktor. Er setzt die Einheit oder Groessenskala der distanzartigen Lesart. Ohne eine zusaetzliche physikalische Bindung ist `l0` hier kein Beweis fuer eine konkrete physikalische Laengenskala.

Wichtig ist die Grenze:

```text
d_ij ist in dieser Notiz eine relational distance construction.
Sie ist keine fertig rekonstruierte physikalische Raumzeitmetrik.
```

## 5. Why the logarithm matters

Der Logarithmus ist deshalb naheliegend, weil er multiplikative Beziehungen in additive Groessen verwandeln kann.

Wenn Korrelationen entlang mehrerer Schritte multipliziert auftreten, kann eine logarithmische Lesart diese Verkettung in eine Summe von distanzartigen Beitraegen uebersetzen. Das ist mathematisch nuetzlich, weil Distanzen in Graphen, Pfaden und Geometrie-Analogien oft additiv gelesen werden.

Kurz gesagt:

```text
Multiplikative correlation structure
-> logarithmic transform
-> additive distance-like reading
```

Das ist eine Brueckenintuition. Sie beweist noch keine physikalische Geometrie.

## 6. Why the absolute value matters

Der Betrag in

```text
|K_ij|
```

bedeutet: Die einfache distanzartige Lesart nutzt hier die Korrelationsstaerke, also die Magnitude des Overlaps.

Das heisst nicht, dass Phase unwichtig ist. Phaseninformation bleibt fuer Interferenz, Dynamik und feinere Struktur relevant. Sie wird in dieser einfachen Distanzlesart nur nicht direkt als Vorzeichen oder komplexe Phase in `d_ij` eingesetzt.

Die sichere Formulierung ist:

```text
The distance-like readout uses correlation magnitude.
Phase information is not denied; it is separated from this simple distance-like readout.
```

## 7. Graph interpretation

Das Graphbild hilft, die Konstruktion anschaulich zu halten:

```text
nodes = states / modeled units
edges = relations / correlations / weights
weights = Staerke oder Form der Relation
graph diagnostics = Werkzeuge, um die relationale Struktur zu inspizieren
```

In diesem Bild ist ein Graph keine physikalische Raumzeit. Er ist eine organisierte Darstellung von Beziehungen.

Wenn im Workstream von Geometry Proxy gesprochen wird, ist damit eine graph-diagnostic proxy behavior gemeint: bestimmte Graphdiagnostiken koennen geometrieaehnlich lesbar sein. Das bleibt Proxy-Sprache.

