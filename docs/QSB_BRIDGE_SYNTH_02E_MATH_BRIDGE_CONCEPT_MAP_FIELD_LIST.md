# QSB-BRIDGE-SYNTH-02E Math Bridge Concept Map Field List

## Field: concept_id

Field type: string identifier

Field description: Stable identifier for one mathematical bridge concept.

## Field: concept_name

Field type: text

Field description: Human-readable name of the concept.

## Field: formula_or_symbol

Field type: text

Field description: Formula, symbol, or notation associated with the concept.

## Field: human_reading

Field type: text

Field description: Plain-language explanation of how the concept should be read.

## Field: role_in_bridge

Field type: text

Field description: Role of the concept in the mathematical or methodical bridge interpretation.

## Field: current_support_status

Field type: controlled string

Field description: Current support class, using conceptual_anchor, documentation_supported, proxy_supported_with_boundary, gap_or_future_work, or boundary_only.

## Field: required_boundary

Field type: text

Field description: Claim boundary that must remain attached when the concept is reused.

## Field: forbidden_overclaim

Field type: text

Field description: Overclaim or excluded interpretation for the concept.

## Field: next_research_move

Field type: text

Field description: Conservative next step associated with the concept.

## Field: notes

Field type: text

Field description: Additional clarification about concept use, risk, or interpretation.
