# QSB-CAUSALITY02B Acyclicity Argument

## Befund

Die Definition von $\Omega_1(X)$ über transitive verfeinerte Zulässigkeit ist zirkelfrei als formaler Aufbau, solange die primitive Zulässigkeitskante selbst nicht zyklisch angenommen wird. Eine echte Azyklizität folgt daraus jedoch nicht automatisch.

## Interpretation

Wenn $X_0\prec_0X_1\prec_0\dots\prec_0X_n=X_0$ angenommen wird, dann folgt

$$\Omega_1(X_0)\supsetneq\Omega_1(X_1)\supsetneq\dots\supsetneq\Omega_1(X_n)=\Omega_1(X_0),$$

was unmöglich ist. Daher ist Azyklizität unter strikter Inklusion formal unterstützt.

## Wohlfundiertheit

Strikte Inklusion schließt endliche Zyklen aus, aber nicht notwendigerweise unendliche absteigende Ketten

$$\Omega_1(X_0)\supsetneq\Omega_1(X_1)\supsetneq\Omega_1(X_2)\supsetneq\dots$$

Das ist kein Zyklus, sondern ein separates Wohlfundiertheitsproblem.

## Hypothese

Ein vollständiger Wohlfundigkeitsnachweis würde zusätzliche Bedingungen benötigen, etwa lokale Endlichkeit, eine Rangfunktion oder eine Abbruchbedingung.

## Claim Boundary

Dieser Block unterstützt nur eine formale Kandidatenstruktur für zeitfreie Fortsetzungen. Er legt keine vollständige Azyklizität oder eine physikalische Ordnung fest.
