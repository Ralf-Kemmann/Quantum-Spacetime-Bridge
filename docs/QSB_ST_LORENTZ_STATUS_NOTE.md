## Lorentz Status Note

Guiding principle:

"Die Idee ins Licht. Die Grenzen ans Geländer. Die Details in den Maschinenraum."

## 1. Purpose

This note gives QSB-ST a clear way to speak about Lorentz-related structure without overstating the current theory status. Its positive purpose is to keep useful compatibility, analogy, and candidate-emergence language available while separating it from derivation claims.

This is not a proof, not a derivation of relativity, and not a result note. It is a claim-discipline and theory-status document that classifies how Lorentz-related language may currently be used in QSB-ST.

## 2. Why Lorentz status matters

The Bridge Nature Working Model treats QSB-ST as a candidate translation layer between quantum phase/coherence/correlation language and relativistic geometry/causality language. That makes Lorentz status important: a bridge that uses RT-like language must say whether Lorentz structure is inspired, assumed, compatible, open, emergent candidate, or derived.

Without that distinction, a chosen wave equation, a geometry-readable distance, or a delay-like readout could be mistaken for a stronger result than it is. Lorentz status keeps the model readable under controlled conditions while protecting the claim boundary.

## 3. Current status in one sentence

QSB-ST is currently best described as Lorentz-compatible or Lorentz-inspired under specified assumptions, but not Lorentz-derived.

QSB-ST ist derzeit unter bestimmten Annahmen am saubersten als Lorentz-kompatibel bzw. Lorentz-inspiriert zu beschreiben, aber nicht als aus der relationalen Struktur abgeleitete Lorentz-Theorie.

## 4. Status categories

1. Lorentz-inspired: The model uses concepts, language, or structural analogies motivated by relativistic physics, but does not derive Lorentz symmetry.
2. Lorentz-compatible: The model is constructed so that it does not obviously contradict Lorentz-related constraints within a stated regime, but compatibility is not a derivation.
3. Lorentz-assumed: Lorentz structure is introduced as an assumption, boundary condition, background structure, or chosen equation form.
4. Lorentz-emergent candidate: A future stronger status in which Lorentz-like structure appears from relational dynamics under explicit assumptions and survives tests.
5. Lorentz-derived: A strong status not currently reached. It would require a derivation of Lorentz symmetry or Lorentz-covariant structure from the underlying relational framework, not merely choosing a Lorentz-compatible equation.
6. Lorentz-open: Questions still unresolved: causal cones, covariance, simultaneity, signal propagation, observer transformations, and relation to metric structure.

## 10. Causality and no-signalling implications

Lorentz compatibility is not only about equations. It also requires that Bridge language does not imply superluminal signalling or uncontrolled causal influence.

The core boundary is simple: correlation is not signalling, and correlation is not causality. Information-channel language requires no-signalling boundaries. Relational delay ordering is not automatically causal order. Perturbation-response tests must distinguish influence, signalling, and correlation.

QSB-ST can keep causal-readability and information-channel language as candidate language, but stronger claims require no-signalling compatibility, operational criteria, and explicit tests.

## 12. Failure and warning modes

Important failure and warning modes:

- treating wave-equation form as relativity,
- treating correlation as signalling,
- treating delay readout as causal cone,
- treating `D_rel` or `d_ij` as spacetime interval,
- using geometry readability as physical metric,
- treating compatibility as derivation,

- overusing strong terms before the positive working model is clear.

These warning modes keep the current language grounded: compatible, inspired, assumed, candidate, under specified assumptions, and not derived.
