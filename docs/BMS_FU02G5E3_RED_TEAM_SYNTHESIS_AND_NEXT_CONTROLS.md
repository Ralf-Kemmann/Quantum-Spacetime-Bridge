## 6. Main Red-Team Criticisms

### 6.1 Tautology risk

The hard red-team criticism is that FU02g5c defines role transport so strictly that the result partly follows from the rule:

```text
Only candidates that are face-type-preserving isomorphic to the reference
are allowed to receive reference roles.
```

Therefore, the statement:

```text
Only the isomorphic candidate receives role transport.
```

is not a surprising empirical discovery. It is primarily a consistency result under a conservative rule.

Accepted response:

```text
Yes. FU02g5e2 should be framed as a defensive consistency/classification block,
not as a strong positive evidence block.
```

Allowed wording:

```text
FU02g5e2 tests the consequences of the pre-specified automorphy-only role-transport rule
on the scaffold-localized near-candidate set.
```

Avoid:

```text
FU02g5e2 proves that only one candidate is physically meaningful.
```

---

### 6.2 Missing FU02g4c raw-order replay certification

The reviews agree that:

```text
fu02g4c_order_guarantee = False
```

is a major limitation.

FU02g5e1 and FU02g5e2 operate on a scaffold-localized candidate set. The candidate set is useful, but not yet certified as an exact replay of the original FU02g4c raw enumeration order.

Accepted response:

```text
FU02g5f must certify whether the g5e1/g5e2 candidate indices and node sets
correspond to the original FU02g4c enumeration outputs.
```

Until then:

```text
All g5e1/g5e2 statements must include the qualifier:
scaffold-localized candidate set, pending FU02g4c raw-order replay certification.
```

Accepted response:

```text

```

Working interpretation:

```text

the coarse diagnostic agrees, but the induced graph topology differs.
```

This must be tested, not merely asserted.

### 6.4 near_distance vs exact/isomorphism ambiguity

The reviewers agree that `near_distance` must be defined more sharply.

Required clarification:

```text
near_distance is a coarse diagnostic distance.
near_distance = 0 does not imply:
- exact role-colored signature identity
- graph isomorphism
- face-type-preserving isomorphism
- role-transport eligibility
```

Recommended wording:

```text
near_distance is used as a coarse screening measure. It is necessary for near-candidate
selection but not sufficient for exact match status, isomorphism, or role transport.
```

before being applied. They cannot be used retrospectively to strengthen g5e2.
