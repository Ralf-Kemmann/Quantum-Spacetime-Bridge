# QSB-CAUSALITY02A Claim Boundary

Dieser Block beschränkt sich auf die formale Prüfung der Kandidatenfunktion

$$d_{ij} = -\ell_0 \log |K_{ij}|.$$

Unterstützt sind:

- ein symmetrisches relationales Unähnlichkeitsmaß,
- bedingte relationale Nachbarschaften,
- eine zeitfreie Zulässigkeitsbeschränkung durch Distanz,
- keine strikte Monotonie aus $d_{ij}$ allein.

Nicht unterstützt sind:

- physikalischer Raumabstand,
- Kausalrichtung aus $d_{ij}$,
- Azyklizitätsbeweis durch $d_{ij}$,
- Eigenzeit aus $\tau$,
- emergente Zeit oder Geometrie,
- Lorentz- oder GR-Grenzfall.
