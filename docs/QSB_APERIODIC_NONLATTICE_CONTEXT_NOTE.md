## 1. Purpose

This note records how recent literature on aperiodic, quasiperiodic, quasicrystalline, and non-lattice discrete spacetime structures should be used inside QSB.

It is not a claim that QSB is a spacetime-quasicrystal model.

It is a context note for careful comparison, vocabulary, controls, and red-team boundaries.

## 2. Core Literature Context

The relevant literature is not one unified field but a bundle of partly connected strands:

```text
1. Mathematical aperiodic order
   Penrose tilings, Ammann-Beenker structures, cut-and-project constructions,
   Delone/Meyer sets, model sets, finite local complexity.

2. Non-lattice discrete Lorentz geometry
   causal set theory, local finiteness, order-plus-number,
   Lorentz-invariant discreteness via Poisson sprinkling.

3. Newer Lorentzian / Minkowski / hyperbolic / conformal quasicrystal work
   spacetime quasicrystals, conformal quasicrystals,
   hyperbolic honeycomb boundary structures.

4. String-theoretic quasicrystalline compactifications
   Narain lattices, asymmetric orbifolds, irrational symmetries,
   often non-geometric CFT settings.
```

The mature part is the mathematics of aperiodic order. The most physically developed non-lattice spacetime program is causal set theory. The newest Lorentz/Minkowski quasicrystal proposals are mathematically interesting but physically speculative.

Most quasicrystal literature starts with a known background:



The clean distinction is:

```text

QSB:

that may later become geometrically readable.
```

Therefore, the correct relationship is:


## 6. Relation to Causal Set Theory

Causal set theory is the closest major quantum-gravity neighbor in one respect:

```text
It uses non-lattice relational discreteness.
It aims to recover Lorentzian geometry from discrete relational structure.
```

But it differs sharply from QSB:

```text
Causal sets use locally finite partial orders.
QSB currently uses graph-like role-colored carrier patches and automorphism controls.
```

Important warning for QSB:

```text
In causal set theory, Lorentz-compatible discreteness is tied to stochastic
Poisson sprinkling and characteristic nonlocality.
Finite-valent graph structures are not automatically Lorentz-compatible.
```

Consequence:

```text
As long as QSB remains a controlled relational-graph testbed,
this is not fatal.

If QSB later makes physical Lorentz-compatible microstructure claims,
causal set constraints become a hard consistency check.
```

## 8. Controls Inspired by the Literature

The literature suggests several control ideas that can be translated into QSB without overclaiming.

### 8.1 Local complexity

For QSB:

```text
Count local signature classes.
Compare patch diversity against nulls.
Track whether candidate signatures are rare but structurally reproducible.
```

### 8.2 Patch recurrence / rarity

For QSB:

```text
Measure how often a role-colored signature appears.
Separate automorphic copies from independent decoys.
Inspect near-matches separately.
```

### 8.3 Automorphy-controlled equivalence

For QSB:

```text
Do not count symmetry twins as independent structures.
Use automorphism or orbit controls to classify exact matches.
```

### 8.4 Meyer-/Delone-like graph analogues

Potential graph analogues:

```text
separation: candidate motifs are not trivially everywhere
coverage: related motifs are not absent except by construction
controlled differences: near-match space is structured, not arbitrary
```

These are analogies, not imported theorems.

### 8.5 Geometric readability via invariants

For QSB:

```text
Prefer invariant diagnostics before embedding claims.
Use graph metrics, role-degree histograms, automorphism classes,
spectral measures, motif counts, and geometry proxies before saying "space".
```
