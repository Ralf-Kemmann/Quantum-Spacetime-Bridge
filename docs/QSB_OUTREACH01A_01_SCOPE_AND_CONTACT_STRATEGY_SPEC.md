# QSB-OUTREACH01A-01 - Scope and Contact Strategy Specification

## Status

Draft for internal review.

## Purpose

Prepare a mathematically transparent, data-grounded, and reproducible contact package for researchers working on discrete time crystals and period-doubled laser dynamics.

## Primary External Relevance

- observable recurrence
- temporal phase equivalence
- cycle instance identity
- state-class representation
- temporal domains and transitions
- transparent transformation and lineage handling

## In Scope

1. Formal state representation.
2. Explicit equivalence relations.
3. Relational similarity and graph construction.
4. Synthetic control cases.
5. Sensitivity and negative controls.
6. DWH-backed lineage.
7. Human-readable language views.
8. A short external technical note and contact gate.

## Out Of Scope

1. Validation of QSB as a whole.
2. Claims about fundamental discreteness of time.
3. Claims about emergent spacetime or gravity.
4. Replacement of established nonlinear-dynamics methods.
5. Requests for endorsement, arXiv access, journal support, or collaboration status in the first contact.
6. Personal-meeting logistics in the first contact.

## Central Question

Can a relational representation that separates observable recurrence, phase equivalence, cycle instance, and full state identity provide a useful complementary description of period-doubled laser dynamics?

## Deliverables

- mathematical specification
- canonical DWH schema
- multilingual presentation views
- synthetic demonstrator
- sensitivity result note
- external technical note
- contact-gate decision
- first-contact email draft

## Contact Gate

The package may proceed to external contact only if:

- all mathematical symbols are operationally defined;
- the complete data route is documented;
- positive and negative controls are reproducible;
- parameter sensitivity is reported;
- non-claims are explicit;
- a reviewer can identify where to disagree;
- the first contact asks for technical assessment, not endorsement.
