# QSB-BRIDGE-SYNTH-02B Masterchat Integration Index Field List

## Field: integration_id

Field type: string identifier

Field description: Stable identifier for one Masterchat integration row.

## Field: section

Field type: text

Field description: Human-readable section or topic name for the integration row.

## Field: source_artifact

Field type: text

Field description: Existing source artifact or artifacts used for the integration statement.

## Field: integration_statement

Field type: text

Field description: Compact statement to carry into a Masterchat, project overview, method note, gap register, or next-work anchor.

## Field: documentation_use

Field type: controlled string

Field description: Intended documentation context, using masterchat_summary, internal_method_note, project_status_anchor, gap_register, or next_work_anchor.

## Field: required_boundary

Field type: text

Field description: Required boundary that must remain attached when the integration statement is reused.

## Field: forbidden_overclaim

Field type: text

Field description: Overclaim or excluded interpretation for the integration statement. Gap-register rows may use not_applicable_for_gap_register.

## Field: next_action

Field type: text

Field description: Conservative next action associated with the integration row.

## Field: notes

Field type: text

Field description: Additional clarification about the intended use or limitation of the integration row.
