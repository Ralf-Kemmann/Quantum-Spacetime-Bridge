# QSB-BRIDGE-SYNTH-02C Public-Cautious Claims Field List

## Field: public_claim_id

Field type: string identifier

Field description: Stable identifier for one public-cautious claim row.

## Field: public_statement

Field type: text

Field description: Public-facing statement, phrased cautiously and without physical proof language.

## Field: status

Field type: controlled string

Field description: Public-use status of the statement, using public_safe_with_boundary, public_safe_as_limitation, internal_context_only, or not_public_claim.

## Field: support_basis

Field type: text

Field description: Existing source artifacts supporting the public-cautious statement.

## Field: required_boundary

Field type: text

Field description: Boundary that must remain attached whenever the statement is reused.

## Field: forbidden_overclaim

Field type: text

Field description: Overclaim or public wording that the row explicitly excludes.

## Field: recommended_use

Field type: text

Field description: Suggested public or semi-public context for the statement.

## Field: risk_level

Field type: controlled string

Field description: Risk that the statement could be misunderstood or overread, using low, medium, or high.

## Field: notes

Field type: text

Field description: Additional clarification about use, risk, or interpretation.
