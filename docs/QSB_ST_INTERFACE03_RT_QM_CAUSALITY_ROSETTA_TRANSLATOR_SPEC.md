## 1. Purpose

This document specifies the next controlled vocabulary layer for QSB-ST.

The working question is not whether relativity theory (RT) and quantum mechanics (QM) are secretly identical. The working question is whether selected terms, observables, and structural roles of relativistic causal geometry can be mapped into a quantum/wave-relational vocabulary without flattening either side.

QSB-ST is treated here as a possible **interface layer** or **translator layer** between two already powerful and well-tested theory systems:

- relativity theory, with its vocabulary of spacetime, metric structure, causal cones, geodesics, proper time, curvature, and gravitational propagation effects;
- quantum mechanics / wave mechanics, with its vocabulary of phase, amplitude, frequency, wavelength, momentum, energy, overlap, coherence, interference, spectrum, and correlation.

The aim of INTERFACE03 is to define a disciplined translation pattern:

```text
RT term → structural role → QSB-ST proxy → QM/wave carrier → modification rule → claim boundary
```

This is a **Rosetta-style vocabulary scaffold**, not a theory claim.

## 2. Core framing: interface instead of replacement theory

QSB-ST does not attempt to replace relativity theory or quantum mechanics. The project frame is smaller and more technical:

> When two mature systems use different internal structures and cannot communicate directly, the missing element may not be a larger theory, but a carefully specified interface, translator, or protocol layer.

In this document, RT and QM are treated analogously to two mature operating environments with different internal logic. Both can be internally coherent and empirically strong, yet still require an interface layer for controlled translation between their vocabularies.

The central QSB-ST image is therefore not a grand unification machine, but a small valve:

```text
RT side: geometric causal readability
QM side: wave/phase/energy-momentum readability
QSB-ST side: controlled interface vocabulary and diagnostic gates
```

The translator must not use naive one-to-one identities.

Forbidden style:

```text

```

Preferred style:

```text

        → candidate relational proxy

```

Example:

```text

Structural role: systematic change in geometry, path structure, or causal accessibility
QSB-ST proxy: drift in relational neighborhoods, path weights, spectral organization, or fingerprint deformation
QM/wave carrier: phase gradients, Δk, Δp, coherence/overlap changes, spectral shifts
Boundary: not a derivation or measurement of Riemann curvature
```

This role-based mapping is the central discipline rule of INTERFACE03.

## 4. Causality formation as the key interface problem

The most important translation problem is **causality formation**.

Relativity theory treats causal structure geometrically:

```text
spacetime metric → light cones → timelike/null/spacelike separation → allowed causal reachability
```

Quantum mechanics speaks in a different language:

```text
state → amplitude → phase → operator/order → measurement/correlation → transition structure
```

QSB-ST therefore asks:

> How can a relativistically readable causal order become connected to, or emerge from, stabilized relational quantum/wave structure?

This is not a claim that QSB-ST derives relativistic causality. It is a vocabulary and diagnostic question:

```text
correlation → stable relation → directed accessibility → causal readability → geometric causal structure
```

### Working definition

**Causality formation** denotes the candidate transition from pre-geometric, not-yet-classically-time-ordered, or merely correlational structure toward a relativistically readable causal order.

This keeps the project away from assuming that causality must already be primitive at the earliest interface level.

```text

```

## 6. Rosetta candidate: c as interface constant

The first strong Rosetta candidate is the constant `c`.

The claim is not that QSB-ST explains the numerical value of `c`. The claim is only that `c` appears in central relations on both the RT side and the QM/wave side, with a clear structural translation role.

### 6.1 RT-side role of c

On the RT side, `c` is not merely the speed of light. It is the conversion constant that links spatial separation and temporal ordering within causal geometry.

It appears as:

```text
light-cone norm
causal speed limit
space-time conversion factor
metric conversion between spatial and temporal units
```

For example, in flat spacetime:

```text
ds² = c² dt² - dx²
```

### 6.2 QM/wave-side role of c

On the wave/QM side, for massless radiation:

```text
E = h f = ħω
p = h / λ = ħk
E = pc
```

Therefore:

```text
c = λ f = ω/k = E/p
```

This is the first Rosetta line:

```text
c connects temporal oscillation, spatial wavelength, phase structure, energy, and momentum.
```

### 6.3 Massless case

For photons or massless excitations:

```text
E/p = c
ω/k = c
λ f = c
```

QSB-ST reading:

```text
The relativistic causal propagation scale coincides with the wave/phase and energy-momentum ratio.
```

Boundary:

```text
This is standard physics. QSB-ST does not claim novelty here.
The novelty, if any, lies only in using this as a disciplined translator slot.
```

### 6.4 Massive case and warning

For massive particles, the relation is not simply `E/p = c`.

Relativistically:

```text
E² = p²c² + m²c⁴
v_group = dE/dp = pc²/E
E/p = c²/v_group
```

Thus:

```text
E/p = c only in the massless limit or in the ultra-relativistic limit approaching c.
```

This warning is mandatory in any future use of the Rosetta-c relation.

### 6.5 Compton-scale relation

For massive particles, the Compton scales provide another useful translator relation:

```text
f_C = mc²/h
λ_C = h/(mc)
λ_C f_C = c
```

QSB-ST reading:

```text
Even for massive particles, c links a temporal oscillation scale and a spatial quantum scale.
```

Boundary:

```text
This does not prove that mass generates spacetime.
This does not derive c.
This does not establish a Bridge mechanism.
```

## 7. c as phase coupler

For a plane wave:

```text
φ = kx - ωt
```

For massless radiation:

```text
ω = ck
```

Thus:

```text
φ = k(x - ct)
```

QSB-ST translator reading:

```text
c couples the spatial phase part kx to the temporal phase part ωt.
```

This is important for causality formation because relativistic causal readability may require stable phase relations that can be interpreted geometrically.

Candidate phrasing:

```text
c may be treated as a controlled interface constant between spatial phase structure, temporal oscillation, and causal propagation readability.
```

Boundary:

```text
This is a vocabulary scaffold, not a derivation of causal geometry.
```

## 9. ShapiroInfo as first use case

INTERFACE03 prepares the later SHAPIROINFO01 block.

The Shapiro effect is not to be modified, replaced, or re-explained. Standard GR remains the baseline.

QSB-ST asks only a secondary diagnostic question:

> If two otherwise comparable signals follow different gravitational/geometrical environments, and all known standard effects are corrected, does any reproducible information/fingerprint residual remain?

Signal comparison frame:

```text
Signal A: reference path / less affected path
Signal B: path through stronger gravitational/geometrical environment
```

Standard correction layers:

```text
GR Shapiro delay
medium / plasma
source variability
instrument response
calibration drift
lensing
noise
sampling
processing pipeline effects
```

Residual logic:

```text
B = A + known standard effects
→ no additional QSB-ST residual

B != A + known standard effects
→ candidate information residual only, if reproducible and controlled
```

Mandatory boundary:

```text
A candidate residual would not confirm the Bridge.
It would only justify a narrower diagnostic follow-up.
```
