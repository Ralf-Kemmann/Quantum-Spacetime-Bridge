# QSB-CAUSALITY01 Concept Note

## Finding

The relational objects in this block are defined at the level of compatibility, overlap, or correlation between local states. The minimal symbolic starting point is

- $K_{ij} = \langle \psi_i | \psi_j \rangle$
- optionally $C_{ij} = \mathcal{C}(\psi_i, \psi_j, \mathcal{E}_{ij})$

These objects describe a relation between two local records, not yet a physical spacetime interval. The candidate distance form

- $d_{ij} = -\ell_0 \log |K_{ij}|$

is treated as a relational measure only and must not be identified with an established physical distance.

## Interpretation

A directed formation relation $i \prec j$ can be introduced as a local dependency condition: the stable update at $j$ requires a permitted prior compatibility condition at $i$. This is a plausible minimal language for a partial ordering, but it does not yet establish a full causal mechanism.

The central distinction remains:

- correlation is not yet causality
- a latency parameter is not yet a fundamental clock
- an emergent time axis is still a conjectural bookkeeping device

## Hypothesis

The working hypothesis is that the direction of a stable relation can arise from one or more of the following: finite formation latency, irreversible record formation, local consistency constraints, or stability selection. The role of $\tau_{ij}$ should be treated as derived correlation latency unless stronger evidence appears.

## Open gap

The missing step is a minimal rule that converts compatibility into a directed, acyclic formation relation without presupposing classical time or an external global clock. This note therefore defines the architecture of the question, but does not claim an emergent geometry or a recovered Lorentzian limit.

## Claim Boundary

This note does not establish a causal mechanism, does not derive spacetime, and does not claim a validated physical theory.
