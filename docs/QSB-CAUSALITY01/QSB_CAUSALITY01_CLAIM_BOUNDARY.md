# QSB-CAUSALITY01 Claim Boundary

This note defines a conceptual bridge from relational compatibility to a directed formation relation, but it does not claim:

- a proven causal mechanism,
- an emergent time axis,
- a derived geometry,
- a recovered Lorentz-invariant limit,
- or a validated physical theory.

The only claim is that the conceptual architecture is now defined as a provisional framework for further formalization.
