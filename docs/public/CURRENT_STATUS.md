# Current Project Status

**Status date:** 26 July 2026

This note is the current public orientation layer for the Quantum–Spacetime Bridge repository. It does not replace the detailed run records.

## Active publication track

### Finite coupled matter–edge-field model

The current manuscript track studies a finite, dimensionless graph model in which a Schrödinger state and edge variables are coupled bidirectionally.

The strongest model-internal results currently available are:

- a closed stationary edge response with a unique stable solution within the defined model;
- replication across 32 independent realisations of the frozen graph-generator family;
- an exact uniform null branch for the free ground state;
- a non-trivial self-consistent branch under an explicit high-fidelity preparation constraint;
- bounded self-consistent time evolution;
- convergence, reversibility, Hermiticity, connectivity, norm, and energy checks;
- small, directionally consistent deviations from the corresponding frozen-edge evolution.

The non-trivial branch is a maintained preparation sector. It is not a freely selected physical ground state.

### Numerical clarification

An earlier preregistered time-evolution run retained its historical `mixed` decision because only part of the trajectories passed very tight conservation thresholds at the original numerical settings.

A separate numerical-adequacy investigation subsequently showed that the discrepancy was explained by combined discretisation and solver error. With refined settings, the original conservation thresholds were passed across all evaluated seeds. The historical decision remains part of the audit trail; the later clarification is documented separately.

## Present scientific boundary

The current work supports an exploratory mathematical and computational study of a finite graph model.

It does not yet provide:

- a derivation of physical spacetime;
- a physical theory of gravitation;
- Lorentz covariance or physical causal structure;
- a physically calibrated edge or metric variable;
- a freely generated de Broglie-ordered ground state;
- matter-specific or isotope-specific predictions;
- an experimental or astronomical signature.

The present manuscript must therefore remain mathematically confident and physically cautious.

## Research infrastructure track

The project uses a PostgreSQL research data warehouse, metadata-controlled lineage, validation and repair states, and a multidimensional research hypercube.

Spectral data and other research values can be held in a jointly addressable analytical space. Domain Data Marts are linked only through documented metadata and join contracts. This infrastructure is treated as a research instrument in its own right and is intended for a separate computational-physics or research-data methods paper.
