# QSB v0.2.0 — Public research surface and metadata infrastructure

**Release date:** 26 July 2026

## Purpose

This release freezes the first publication-oriented public repository surface of the Quantum–Spacetime Bridge project.

It is a citable repository snapshot and a research-infrastructure baseline. It is **not** a release of a validated physical theory of spacetime or gravitation.

## Included in this release

### Public research orientation

- a current root README;
- explicit scientific claim boundaries;
- a current-status document;
- a repository navigation guide;
- a German-language overview;
- a publication roadmap;
- a transparent human–AI method note;
- a clear distinction between evidence-bearing figures and conceptual editorial illustrations.

### Current physics publication track

The repository documents the finite, dimensionless coupled matter–edge-field graph model, including:

- exact model structure;
- cross-seed numerical replication;
- free and constrained branches;
- bounded self-consistent time evolution;
- numerical adequacy and control checks;
- explicit physical limitations.

The release does not upgrade the model-internal results into claims about physical spacetime, gravitation, Lorentz covariance, or an experimentally established de Broglie mechanism.

### Research data infrastructure

The public documentation now describes:

- the PostgreSQL research data warehouse;
- source and version lineage;
- units, dimensions, validation, repair, control, and claim metadata;
- domain-specific Data Marts;
- the n-dimensional scientific hypercube;
- metadata-governed Slice, Dice, Pivot, Roll-up, Drill-down, Drill-through, and Drill-across analysis;
- preservation of positive, neutral, rejected, unresolved, and repair-required outcomes.
