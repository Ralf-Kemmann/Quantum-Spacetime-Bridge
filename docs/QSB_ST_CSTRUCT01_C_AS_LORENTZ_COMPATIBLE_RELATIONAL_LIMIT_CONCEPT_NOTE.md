## 2. Origin question

The motivating question is whether QSB-ST should try to explain the speed of light.

## 3. c as numerical value versus c as structure

There are two different things that can be called "c":

- the numerical SI value, `299,792,458 m/s`
- the existence of a universal invariant speed that structures causal ordering, simultaneity relations, and Lorentz-compatible transformations

The first is unit-dependent. Its numerical expression depends on how metres and seconds are defined. It is not the deep invariant target for QSB-ST.

The second is structural. It says that physical descriptions are organized around an invariant causal limit shared across inertial frames. That structural role is the only form in which `c` can responsibly enter the current QSB-ST concept line.

## 4. Why the numerical value is not the deep target

QSB-ST should not try to "derive 299,792,458 m/s" as a bare number.

That number is tied to SI conventions. Treating it as the target would risk confusing a unit convention with a structural physical condition.

The deeper target, if one is ever approached, would be the existence and necessity of an invariant causal limit. In this project line, `c` may be better treated, not as a target number to be fitted, but as the structural signature of a Lorentz-compatible relational limit.
