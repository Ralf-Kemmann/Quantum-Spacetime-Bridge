# QSB-ST Resonance Matter Signature
## Marker-vs-Carrier Status Table

Guiding principle:

"Die Idee ins Licht. Die Grenzen ans Geländer. Die Details in den Maschinenraum."

## 1. Purpose

This document gives the QSB-ST project a compact status table for central objects, layers, and readouts. Its positive purpose is to keep useful candidate structures visible while preventing silent upgrades from marker to carrier, readout to physical observable, or archival result to canonical result.

This is not a result note and not a theory proof. It is a status/claim-discipline document that classifies central QSB-ST objects as candidate carrier, marker layer, diagnostic readout, modifier axis, control scaffold, or open object.

## 2. Core distinction

Carrier is not the same as marker.

Marker is not the same as readout.

Readout is not the same as physical observable.

Diagnostic success is not physical validation.

Definitions:

- Carrier: A structure that could physically or informationally carry bridge-relevant organization.
- Candidate carrier: A plausible carrier under investigation, not yet established.
- Marker layer: A feature or layer that may track bridge-relevant organization without being the underlying carrier.
- Diagnostic readout: A computed output used to test stability, specificity, geometry-readability, mimicry, or failure modes.
- Modifier axis: A descriptor family or matter-sensitive axis that may modify or stratify marker behavior but is not itself a carrier.
- Control scaffold: A deliberately constructed test system used to calibrate diagnostics, expose mimicry, or test failure modes.
- Open object: A structure whose status is not yet clear.

## 5. Candidate carrier path

The current candidate carrier path starts with `K_ij`, the phase relation layer, and the phase-coherent off-diagonal relational correlation structure. The most promising formal route is a density matrix / rho route that can describe off-diagonal order, decoherence response, open-system behavior, and possibly an ODLRO-like stability pattern.

This path remains candidate, not established. To move upward, it needs PADS-01 phase/amplitude decoupling support, strong null-model gaps, mimicry resistance, density-matrix or open-system formalization, and compatibility with geometry, causality, entropy, and carrier criteria.

## 6. Marker and readout path

The marker/readout path includes `|K| / G`, `D_rel`, `d_ij = -l0 log |K_ij|`, `D(A,B)`, negative/abs, the positive channel, bridge carrier blocks C/D/E, and the bridge minimal model.

These objects may be useful because they expose structure, stratification, geometry-readability, or failure modes. Their current role is marker, readout, or diagnostic model. They should not be upgraded to carrier status unless they are connected to a stable carrier candidate and pass the relevant controls.

## 7. Matter Signature and Carbon path

Matter Signature axes, VDW axis, isotope axes, QC descriptors, shell descriptors, and valence descriptors are currently modifier axes or marker layers. They may support matter-sensitive stratification if canonical reruns support pre-registered hypotheses without score engineering or weak controls.

Carbon diagnostics are a control scaffold and scanner calibration line. Carbon helps test mimicry, label sensitivity, topology sensitivity, local-structure traps, and scanner behavior. Carbon diagnostics do not by themselves validate a molecular Bridge.

For recovered older Matter Signature runs, the practical work is to Herkunft und Nachvollziehbarkeit klären, alte Runs sauber zuordnen, Fundstellen und Reproduzierbarkeit prüfen, alte Ergebnisdateien nachvollziehbar einordnen, and klären, welche alten Runs reproduzierbar sind.

## 8. Geometry / causality / entropy readouts

Geometry-related readouts include `d_ij = -l0 log |K_ij|`, `D(A,B)`, geometry readability, metric-readable regimes, Green/Poisson readout, and Coulomb-like readout. These can support Geometry Anchor tests only when an external observable, declared scaling law, or interaction-form anchor is present.

Temporal and causal readouts include Hartman / Dwell delay, Relational Delay, and causal asymmetry / perturbation response. They remain temporal / causal anchor candidates until asymmetry, perturbation response, no-signalling compatibility, and operational testability are defined and tested.

Entropy / stability readouts include entropy, mutual information, coherence readouts, and Boltzmann-type weighting. They can support stability and selection language only when measures, coarse-graining, decoherence behavior, and interpretation boundaries are explicit.

## 9. Upgrade conditions

Before a marker/readout can move upward, the following conditions are needed where applicable:

- PADS-01 phase/amplitude decoupling support,
- strong null-model gap,
- mimicry resistance,
- Geometry Anchor support where distance is interpreted,
- canonical rerun for archival Matter Signature axes,
- external observable or declared scaling law,
- density-matrix / open-system formalization where carrier status is claimed,
- no-signalling / causality criteria where information-channel language is used,
- entropy/coherence criteria where stability/selection language is used.

Upgrade should be explicit, documented, and tied to predeclared tests.

## 10. Forbidden upgrades

Forbidden upgrades:

- readout -> carrier,
- marker -> physical observable,
- geometry readability -> physical geometry,
- Matter Signature modifier -> physical RMS carrier,
- VDW marker -> VDW carrier,
- negative/abs marker block -> negative channel carrier,
- Carbon scanner calibration -> molecular bridge validation,
- archival recovered result -> canonical result,
- candidate translation layer -> established physical interaction,
- compatibility with RT/QM -> replacement of RT/QM.

These are forbidden as silent upgrades. Some may become future questions, but only through explicit criteria and new evidence.
