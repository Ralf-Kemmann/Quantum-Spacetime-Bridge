# QSB-BRIDGE-DATA-02C Control Ensembles

This directory contains synthetic/reference-style control ensemble declarations and generated tables for QSB-BRIDGE-DATA-02C.

No external data are bundled here. No data are downloaded by the DATA-02C script.

DATA-02C instantiates controls for the DATA-02B carbon bonding-organization ladder. It is not real-data validation, molecular validation, or physical validation.

Controls are generated deterministically with a fixed seed.
