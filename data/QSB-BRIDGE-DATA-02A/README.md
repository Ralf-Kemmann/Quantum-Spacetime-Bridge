# QSB-BRIDGE-DATA-02A Data Scaffold Inputs

This directory contains synthetic/reference-style scaffold declarations and generated tables for QSB-BRIDGE-DATA-02A.

No external data are bundled here. No data are downloaded by the DATA-02A script.

DATA-02A is not real-data validation, physical validation, or molecular validation. It creates a controlled sp2 contrast scaffold for benzene versus C60 so later blocks can test table contracts, proxy-risk labels, and contrast diagnostics before real-data interpretation is attempted.

The C60 scaffold must be exact and validated before it is marked usable.
