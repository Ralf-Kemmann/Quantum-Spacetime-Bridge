# QSB-BRIDGE-DATA-02D Diagnostic Separation

This directory contains the static configuration and generated data mirrors for QSB-BRIDGE-DATA-02D.

DATA-02D is a synthetic/reference-style diagnostic separation block for the DATA-02B carbon bonding-organization scaffold and DATA-02C control ensembles. It uses only local scaffold/control tables and does not download external data.

The diagnostics are transparent scaffold-level comparisons over labels and graph connectivity:

- topology signature
- degree distribution
- bond-order distribution
- hybridization distribution
- sigma/pi organization
- local environment consistency
- combined bonding-organization score
- original/control separation score

This block is not real-data validation, molecular validation, physical validation, spacetime emergence, or proof of electronic-configuration recognition.

DATA-02D carries forward two explicit cautions:

- QSB-BRIDGE-NUM-05C warning: local-neighborhood sensitivity under small additive magnitude noise at noise level 0.02.
- DATA-02C mimic warning: some controls show zero/low original-control contrast, especially within-system label shuffles for small/uniform systems.

Poor separation, zero contrast, or control mimicry are valid negative or boundary findings.
