# QSB-BRIDGE-DATA-01 Data Preflight Inputs

This directory contains static preflight declarations for QSB-BRIDGE-DATA-01.

No external data are bundled here. No data are downloaded by the DATA-01 script.

The files in this directory are intended to describe candidate systems, candidate source types, required fields, and proxy-risk notes before any real-data validation-like work is attempted.

Files:

```text
candidate_source_registry.csv
preflight_config.json
```

DATA-01 is a preflight only. It records whether later DATA-02 work could proceed with documented provenance, machine-readable source fields, and explicit controls against re-encoding known geometry into `K_ij`.
