# QSB-BRIDGE-DATA-02B Carbon Bonding-Organization Scaffold

This directory contains synthetic/reference-style scaffold declarations and generated tables for QSB-BRIDGE-DATA-02B.

No external data are bundled here. No data are downloaded by the DATA-02B script.

DATA-02B is not real-data validation, molecular validation, or physical validation. It extends the DATA-02A benzene/C60 scaffold into a carbon bonding-organization ladder using carbon-skeleton-only graph nodes.

Hydrogen and saturation are metadata, not primary graph nodes.
