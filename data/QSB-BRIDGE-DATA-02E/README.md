# QSB-BRIDGE-DATA-02E

Synthetic/reference-style control mimicry revision block.

DATA-02E starts from the DATA-02D diagnostic separation result and classifies why
some controls remain original-like. It does not download external data, use
coordinates, or use geometry-derived `K_ij`.

Primary local inputs are the DATA-02D run outputs under:

`runs/QSB-BRIDGE-DATA-02D/diagnostic_separation_open/`

The runner is:

`scripts/qsb_bridge_data02e_control_mimicry_revision.py`

Expected generated mirrors in this directory:

- `control_mimicry_revision_manifest.json`
- `control_mimic_failure_inventory.csv`
- `control_destruction_effectiveness_summary.csv`
- `diagnostic_specificity_summary.csv`
- `mimic_family_risk_summary.csv`
- `revision_recommendation_summary.csv`

Claim boundary: DATA-02E provides no real-data validation, no molecular
validation, no physical validation, no spacetime emergence claim, and no proof
that electronic configurations or bonding organization are physically
recognized.

Persistent mimicry is treated as a valid boundary finding.
