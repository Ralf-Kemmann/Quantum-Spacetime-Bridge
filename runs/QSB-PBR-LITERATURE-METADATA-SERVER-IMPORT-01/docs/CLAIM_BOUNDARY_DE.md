# Claim Boundary

Diese Literaturdaten sind Kontext- und Suchraum-Metadaten.
Sie sind keine interne Evidenz für QSB/PBR.
Sie autorisieren keine physikalischen oder mechanistischen Claims.

- Kontext
- Vokabular
- Vergleichsstruktur
- Red-Team-Fragen
- Orientierung für spätere Mechanismus-Suchräume

## Verbotene Nutzung

- Evidenz
- Ergebnis
- Mechanismusbestätigung
- Physikalischer Claim
