# Data Analyst Handoff

Diese Literaturdaten sind Kontext- und Suchraum-Metadaten.
Sie sind keine interne Evidenz für QSB/PBR.
Sie autorisieren keine physikalischen oder mechanistischen Claims.

## Erlaubte Cube-Nutzung

Der Data Analyst darf die vorbereiteten Literaturtabellen später nutzen für:

- `literature_cluster × qsb_structure_tag`
- `mechanism_thread × literature_density`
- `source_class × risk_status`
- `claim_boundary × allowed_use`

## Nicht erlaubte Nutzung

Die Literaturzeilen dürfen nicht behandelt werden als:

- evidence
- result
- mechanism confirmation
- physics claim

## Status

Der Import ist vorbereitet, aber nicht ausgeführt. Ein menschlich bestätigtes DB-Ziel ist erforderlich.
