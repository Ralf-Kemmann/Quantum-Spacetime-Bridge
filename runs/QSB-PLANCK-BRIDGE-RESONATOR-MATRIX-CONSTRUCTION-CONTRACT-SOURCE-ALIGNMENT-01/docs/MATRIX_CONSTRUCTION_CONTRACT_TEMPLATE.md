# Matrix Construction Contract Template

Required fields for a future design run:

- `contract_id`
- `source_artifact_path`
- `source_sha256`
- `source_type`
- `origin`
- `K_export_path`
- `K_export_sha256`
- `input_pair_table_path`
- `input_pair_table_sha256`
- `pair_id_columns`
- `endpoint_columns`
- `lag_class_or_value_columns`
- `pair_policy`
- `symmetry_policy`
- `diagonal_policy`
- `duplicate_pair_policy`
- `missing_pair_policy`
- `lag_policy_class_definition`
- `matrix_shape`
- `matrix_index_order`
- `entry_formula`
- `weighting_policy`
- `normalization_policy`
- `PSD_eigen_rank_tolerance_policy`
- `randomization_eligibility`
- `reconstruction_command_or_function`
- `expected_output_hash`
- `validation_checks`
- `limitations`
- `claim_boundary`

This template is not a contract and does not unblock execution.
