# Source Patch Implementation Readiness Checklist

Implementation may proceed only if the next run preserves:

- Scoped K-only callable or wrapper.
- Explicit input and output arguments.
- No hidden state dry-run.
- Contract field exports.
- Lag-class handoff export.
- Control policy export.
- Baseline hash or reviewed similarity check.
- CSV schema checks.
- Claim boundary checks.
- Forbidden-scope guards.
