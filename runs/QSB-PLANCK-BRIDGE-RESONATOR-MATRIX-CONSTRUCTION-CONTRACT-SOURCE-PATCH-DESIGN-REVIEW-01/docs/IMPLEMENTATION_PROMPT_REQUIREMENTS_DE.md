# Implementation Prompt Requirements

## Pflichtpunkte

Der naechste Implementierungsprompt muss:

- diesen Review und den Source-Patch-Design-Lauf als Inputs nutzen;
- einen scoped K-only Callable oder Wrapper erstellen;
- Contract-, Lag-Handoff- und Control-Policy-Exports erzeugen;
- unset Human-Value-Felder blockierend behandeln;
- Dry-run no-hidden-state pruefen;
- K Hash oder reviewed similarity validieren;
- Duplicate/Missing-Pair-Negativtests implementieren;
- Claim Boundaries erhalten;
- Suffizienz, Nullmodelle, DWH, Literatur und physikalische Interpretation verbieten.

## Claim Boundary

Der Prompt darf nur Implementierungsinfrastruktur erzeugen.
