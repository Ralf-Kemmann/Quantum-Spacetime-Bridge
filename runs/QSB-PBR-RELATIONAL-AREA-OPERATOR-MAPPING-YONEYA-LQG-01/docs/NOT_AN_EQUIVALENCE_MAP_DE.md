# Not an Equivalence Map

## Befund

String worldsheet area is not LQG area.
Schild action is not the LQG area operator.
Spin-network geometry quanta are not QSB/PBR pairs.
QSB/PBR K_candidate is not a verified physical geometry operator.
This mapping is a formal analogy and design vocabulary only.

## Interpretation

Die Karte dient nur dazu, wiederkehrende mathematische Sprachen nebeneinanderzustellen.
Sie verbindet keine Ontologien und keine physikalischen Theorien.

## Hypothese

Die Nicht-Aequivalenz-Grenze erlaubt trotzdem, formale Fragen nach Projektoren, Inzidenz, Spektrum und Invarianz zu stellen.
