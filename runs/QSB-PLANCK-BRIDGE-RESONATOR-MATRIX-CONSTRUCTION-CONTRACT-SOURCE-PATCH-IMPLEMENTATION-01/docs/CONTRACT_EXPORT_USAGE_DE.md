# Contract Export Usage

## Zweck

Der Export erzeugt:

- `contract_field_export.csv`
- `lag_class_handoff.csv`
- `control_policy_export.csv`
- `dry_run_manifest.json`
- `validation_summary.csv`

## Placeholder

## Claim Boundary
