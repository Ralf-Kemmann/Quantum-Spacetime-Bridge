# Red Team

## Befund

Kandidaten mit gemischter oder unklarer Evidenz werden zum Red-Team-Review geroutet.

## Interpretation

Red-Team-Review verhindert voreilige Alias-/Proxyclaims.

## Hypothese

Manueller Review kann unklare Inventarfelder klären.

## Offene Lücke

Review nicht ausgeführt.

## Claim Boundary

Keine physikalische Freigabe.
