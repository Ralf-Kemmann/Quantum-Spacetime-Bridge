# Experiment Arms and Controls

## Befund

Der Run definiert neun zukuenftige Arme:

- Baseline-Rekonstruktion
- True-Lag-Class-Minimalmodell
- gleich-kardinale Nicht-Lag-Partitionen
- gleiche Klassenzahl mit anderer Kardinalitaet
- Label-Permutation
- Membership-Zerstoerung mit Marginalerhaltung
- Matrixregel-Tautologie-Screen
- Projektor-Algebra-Check
- Pipeline-Order-Handoff

## Interpretation

Die Arme trennen Lag-Spezifitaet von Klassenkardinalitaet, Matrixregel, Labeln, Diagonalpolitik, Symmetriebedingungen und Pipeline-Ordnung.

## Hypothese

Nur wenn der True-Lag-Class-Arm die Zielstruktur reproduziert und gleich-kardinale Nicht-Lag-Kontrollen sowie Matrixregel-Screens dies nicht tun, kann spaeter eine mathematische Lag-Class-Suffizienz diskutiert werden.

## Offene Luecke

Alle Arme sind `designed_not_executed`.

## Claim Boundary

Kein Arm autorisiert physikalische Interpretation.
