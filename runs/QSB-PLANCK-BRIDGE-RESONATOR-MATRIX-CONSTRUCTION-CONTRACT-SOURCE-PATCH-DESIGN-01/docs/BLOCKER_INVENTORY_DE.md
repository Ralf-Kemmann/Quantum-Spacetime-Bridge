# Blocker Inventory

## Befund

Die blockierenden Felder sind in `data/blocker_inventory.csv` dokumentiert.

## Blockergruppen

- Duplicate/Missing Row Policy.
- Duplicate/Missing Pair Policy.
- Lag-Class Column, Definition und Sort Order.
- Missing Value Policy.
- Rank Check Rule.
- Random Seed Policy.
- K-only Callable.
- Validation Command.

## Interpretation

Jeder Blocker verhindert Execution 01A bis zur expliziten Export- oder Contract-Freigabe.

## Claim Boundary

Blocker sind Audit-Gates, keine wissenschaftlichen Resultate.
