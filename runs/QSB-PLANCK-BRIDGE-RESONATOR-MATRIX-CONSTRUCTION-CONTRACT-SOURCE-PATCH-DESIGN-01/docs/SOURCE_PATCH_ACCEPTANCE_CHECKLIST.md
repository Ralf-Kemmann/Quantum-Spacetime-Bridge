# Source Patch Acceptance Checklist

The later implementation is not acceptable unless all items pass:

- K-only callable dry-run works without hidden state.
- Contract field export contains all essential fields.
- Duplicate/missing row and pair policies are explicit.
- Lag-class handoff export is complete and validated.
- Rank and numerical policy are explicit.
- Random seed and trial count policy are explicit.
- Validation command exists.
- Expected K hash or reviewed similarity rule is checked.
- Claim boundaries are preserved.
