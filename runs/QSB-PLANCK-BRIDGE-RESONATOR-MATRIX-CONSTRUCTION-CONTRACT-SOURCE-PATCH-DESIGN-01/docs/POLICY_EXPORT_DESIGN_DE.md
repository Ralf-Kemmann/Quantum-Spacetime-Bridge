# Policy Export Design

## Befund

Policy-Felder sollen in einem Contract Field Export dokumentiert werden.

## Zu exportierende Felder

- Pair Policy.
- Symmetry Policy.
- Diagonal Policy.
- Duplicate Pair Policy.
- Missing Pair Policy.
- Missing Value Policy.
- Floating Point Precision.
- Rank Policy.
- Randomization Policy.

## Interpretation

Nicht belegte Werte duerfen nicht erraten werden. Sie muessen vor Implementierung reviewt oder als required human value markiert werden.

## Claim Boundary

Policy Export ist Reproduktionsinfrastruktur.
