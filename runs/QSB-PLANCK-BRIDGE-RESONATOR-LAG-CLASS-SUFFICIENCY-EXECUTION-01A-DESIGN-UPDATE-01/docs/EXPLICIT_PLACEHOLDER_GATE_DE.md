# Explicit Placeholder Gate

Befund:

- Mehrere Felder bleiben `requires_human_value`.
- Diese Felder sind im Design-Update nicht geloest.

Interpretation:

- Die Platzhalter sind fuer Design sichtbar und akzeptabel.
- Fuer Preflight oder Execution sind sie Blocker, sofern sie nicht geklaert oder explizit deaktiviert werden.

Offene Luecke:

- Es fehlt eine dokumentierte Contract-Value-Entscheidung fuer Lag-, Pair-, Threshold- und Randomization-Felder.

Claim Boundary:

- Keine stillschweigende Wertannahme.
